## 3. 一周目标与能力边界

一周后的目标是建立可继续工作的基础能力. 在教材和讲解辅助下, 应能完成以下工作:

1. 将光刃要求写成明确的坐标、光源假设、尺寸定义、均匀度、功率与轴向评价范围.
2. 用高斯光束和两轴近轴模型做量级估算, 判断哪些参数相互制约, 知道估算的适用边界.
3. 比较至少 2–3 条整形路线, 解释它们对入射场、相干性、效率、传播距离和器件的要求.
4. 复现一个一维能量映射与近轴相位屏的教学原型, 用衍射传播观察它在设计面及邻近面的表现.
5. 读懂并调整一个已有的 MATLAB 传播示例, 完成简单算例的解析对照、采样检查和功率核算.
6. 理解 Zemax 射线、高斯分析和 POP 的分工, 对齐简单算例的输入与指标, 分析现有候选的 21 平面结果.
7. 区分目标函数改善、名义仿真通过、数值可信、光源已确认、制造装调可靠这几种不同结论.

一周不以独立完成任意自由曲面设计、完整高 NA 矢量计算、部分相干光源重建、制造公差放行或实验验收为目标. 这些内容放入长期选修. 如果实际设计结论依赖其中某项, 就补齐相应知识和证据, 或明确保留条件, 不把“选修”解释成可以忽略物理限制.

## 4. 正规方法的含义

本课程以“需求与光源确认 → 尺度和可行性估算 → 方法及结构比较 → 解析初始设计 → 光线与波动模型 → 多平面评价 → 误差与工程检验”为主线.

学界没有一套对所有光源和目标都适用的固定镜片排列. 应学习场映射、积分匀化、振幅裁切/成像和衍射相位设计等方法的原理与适用条件. DOE、SLM、非球面和柱面镜是器件或实现方式, 与方法分类不是严格的一一对应关系.

当前结构作为待解释、可比较的案例. 不预设它一定最优, 也不因其来自自行探索就否定它. 比较其他路线是学习内容; 修改当前工程的结构约束须依据用户后续授权.

## 5. 当前工程背景快照

以下用于让教学贴近工作, 不是新的工程验收文件. 后续实际设计、运行或验收必须重新读取工程中的现行要求.

- 光源: WSLD-405-250m-1, 标称波长 405 nm. 源场、两轴束腰、M²、相干性及物理发光点与模型原点的关系, 要区分已测量、厂家提供和模型假设.
- 现有候选: LD → 高 NA 非球面准直镜 L1 → X 方向定制 Powell-like 非球面 P1 → 正透镜 L2 → Y 方向负柱面镜 L3 → 检测区.
- P1 的模型要求为第一面 Ry=∞、后面平面、无 Y 方向面形项. “Powell-like”是候选描述, 不表示已经证明它满足某个标准 Powell 设计.
- 教学重点是 X 方向能量重分布、Y 方向薄光刃以及它们在传播中的共同约束. X/Y 可分离只是一种有条件的简化.

| 项目 | 教学使用的当前定义 |
|---|---|
| 检测范围 | 可变中心 z0 的 ±5 mm, 最终 21 个实际截面, 间隔 0.5 mm |
| Y 厚度 Dy | 70–130 μm. 在 x=0 上, 从中心向正 Y 找到相对 I(0,0)/e² 的首次下降交点, 距离乘二; 同时检查负侧和对称性 |
| X 宽度 Wx | 完整场的等效平顶全宽 sqrt(12)σx, 要求 ≤7 mm |
| CV5 | 先沿完整 Y 范围积分得到 X 边际分布, 再对光轴中心 ±2.5 mm 内的样本取总体标准差/均值; 每面 ≤0.16 |
| 优化方向 | 21 面等权平均 CV5 为主目标, 同时报完整曲线与极值; 0.05 是期望值, 不新增硬门槛, 不改成最大 CV5 优先 |
| 功率 | 全输出采样窗积分 / 原始模型输入功率 ≥60%; 原始归一化输入为 1.000 W, 不在截光后重新归一化 |
| 空间限制 | 物理发光点到 z0 ≤100 mm; L3 后顶点到 z0 >15 mm; 其他镜间和边缘间隙以工程要求为准 |

Dy 不是 FWHM 或 D4σ. CV5 不是 y=0 切片的 CV. 1 W 是归一化仿真输入, 不是该 LD 的实测输出功率. z0 也不是固定 50 mm 或 100 mm.

## 6. 逐点教学协议

1. 用户发送“第 40 个知识点”“40”或知识点标题时, 从计划读取对应条目. 只解释该点及必要的已学前置内容, 不自动继续到下一点.
2. 每次围绕一个主要问题组织: 与当前工作的关系 → 物理图像 → 最少必要数学 → 一个贴近项目的例子 → 适用边界. 深度由问题决定, 不按模板机械扩写.
3. 公式中的符号、单位、坐标、半径/直径、强度/振幅都先说明. 关键推导保留中间台阶, 不以“显然”跳过关键物理关系.
4. 后续概念如果必须提及, 只用一句话说明用途并标出对应编号, 不提前展开推导. 当前所需的基础不足时, 在当前点内做最小补充; 大块补充交由用户决定.
5. 沿用逐步学习的方式, 不主动追加小测、课后作业或要求用户答题后才能继续. 每日应用是带领完成的设计/仿真演示, 用户可自己操作, 也可看讲解后提出修改.
6. 用户明确说“会了”“跳过”时可以跳过. 跳过的内容只记录为跳过, 不擅自记录为已掌握. 讲解过也不等于已掌握.
7. 用中文讲解, 默认采用英文标点. 图中的轴、方向、单位、面的位置和光传播方向应完整标注. 需要图时优先用有物理含义的示意图或计算图.
8. 所有必修编号固定为 01–42, 选修为 43–60. 后续扩展用新增编号或 40a 等附加项, 不挪动已有编号.
9. 教材用于核对和按需阅读, 不要求逐章通读. 遇到教材记号、符号约定或译名不一致时, 明确解释, 不静默混用.
10. 未获得用户新授权, 不将教学演示扩展为运行大规模优化、修改现有光学工程或宣布实物性能合格.
